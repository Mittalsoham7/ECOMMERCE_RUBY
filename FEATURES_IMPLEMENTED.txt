DATABASE SCHEMA
═══════════════════════════════════════════════════════════════

Tables Created (9 total):
1. products - Product catalog with pricing and inventory
2. categories - Product categories
3. product_categories - Many-to-many join table
4. users - Customer accounts (Devise)
5. provinces - 13 provinces with tax rates (GST, PST, HST)
6. addresses - User shipping addresses
7. orders - Customer orders with totals and status
8. order_items - Order line items with historical pricing
9. active_storage_* - File attachments (images)

Key Relationships:
- User has_many Orders
- User has_many Addresses
- Order has_many OrderItems
- Order belongs_to User
- OrderItem belongs_to Order
- OrderItem belongs_to Product
- Address belongs_to User
- Address belongs_to Province
- Product has_many ProductCategories
- Category has_many ProductCategories
- Product has_many Categories through ProductCategories
